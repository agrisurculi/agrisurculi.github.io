This project is a prototype for an athleisure brand to launch a new season collection.


This is an open project, so I took the liberty to set my own design parameter and did some initial sketches accordingly.

Name:

Virtual pop up shop for Outdoor Voice

Purpose:

Ss2018 campaign and product launch

Size:

Aprox 24ft x 18ft

Setting:

Desert in the west


My inspiration is from a recent trip to Joshua Tree National Park and the architecture by Luis Barragon.


I created the folowing 3d model for the structure of this virtual store.


Here's the plan view and color themes


Rendering is done in C4D and finished in Unity. To maximize the experience in web browser, most objects are 2d images.
